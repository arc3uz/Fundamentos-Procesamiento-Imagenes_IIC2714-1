## 📌 Descripción General

Este repositorio almacena el código fuente, experimentación, cuadernos interactivos y reportes de las actividades prácticas del curso **Fundamentos de Procesamiento de Imágenes**. 

El objetivo de los desarrollos es implementar desde cero los algoritmos fundamentales de visión y procesamiento digital (evitando el uso de cajas negras o librerías de alto nivel para las operaciones solicitadas), priorizando el análisis crítico, la exploración paramétrica y la reproducibilidad técnica.

## 🛠️ Requisitos Globales y Entorno

Para ejecutar cualquiera de las tareas se recomienda un entorno virtual con **Python 3.10+**:

```bash
# Clonar repositorio
git clone https://github.com/arc3uz/Fundamentos-Procesamiento-Imagenes_IIC2714-1.git
cd Fundamentos-Procesamiento-Imagenes_IIC2714-1

# Crear y activar entorno virtual
python3 -m venv .venv
source .venv/bin/activate  # En Linux/macOS (bash/zsh)
# source .venv/bin/activate.fish  # Si usas fish

# Instalar requerimientos base
pip install --upgrade pip
pip install -r requirements.txt
```
